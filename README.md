# СЕВЕР — барбершоп

Сайт онлайн-записи в барбершоп. Написан на чистом Go (net/http + html/template + embed).

## Чем отличается от типичного лендинга

- **Тёмная индустриальная тема** вместо светлого минимализма.
- **Отдельная страница записи** с пошаговой формой (мастер → услуга → слоты → контакты), а не длинный одностраничник.
- **Живые слоты** через API: свободное время подгружается по мастеру и дате.
- **Мои записи** по номеру телефона (in-memory, для демо).
- Без фреймворков на фронте — только ванильный JS.

## Запуск локально

```bash
go run .
# открыть http://localhost:8080
```

Или:

```bash
go build -o sever .
./sever
```

## Деплой на Render

1. Создай Web Service, подключи репозиторий.
2. Build Command: `go build -o sever .`
3. Start Command: `./sever`
4. Или используй Dockerfile (Render подхватит автоматически).

`PORT` берётся из окружения (Render выставляет сам).

## Структура

```
main.go          — сервер, модели, API, in-memory хранилище
templates/       — index, book, my
static/          — CSS + JS
```

Данные о записях живут в памяти процесса — после рестарта пропадают. Для продакшена легко заменить на SQLite / Postgres.
